# Privacy Policy for Phaser DevTools

Last updated: 2026-04-21

Phaser DevTools is a Chrome DevTools extension used to inspect Phaser 3 games locally in your browser.

## Data Collection

Phaser DevTools does not collect, store, transmit, sell, or share personal data.

## Website Access

The extension injects a lightweight page hook on visited pages to detect and inspect Phaser game instances so the DevTools panel can display runtime information. Inspection happens locally in your browser session.

## Remote Services

Phaser DevTools does not send inspected page content, game state, or user data to external servers.

## Data Retention

Phaser DevTools does not retain user data.
